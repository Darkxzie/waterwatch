# Spec-Kit Setup

This repository uses a minimal Spec-Kit layout to keep feature work documented and reviewable.

## Core Files

- `constitution.md` defines project-level operating rules.
- `.specify/templates/feature-spec-template.md` provides the default feature spec structure.
- `specs/` stores approved feature specifications.

## Workflow

1. Copy the feature template into a new `specs/<feature-name>/spec.md`.
2. Fill in the goal, scope, constraints, and verification details before implementation.
3. Keep the spec aligned with the shipped behavior when requirements change.
