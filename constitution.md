# WaterWatch Constitution

## Purpose

WaterWatch exists to help citizens report water issues and help authorities triage and resolve them with clear, accountable workflows.

## Operating Principles

1. Keep citizen-facing reporting simple and accessible.
2. Preserve auditable complaint status and assignment flows.
3. Prefer small, testable changes over broad rewrites.
4. Keep API and UI contracts explicit and shared where possible.
5. Maintain deployable quality gates for format, lint, type checking, tests, and coverage.

## Delivery Rules

1. New behavior should be documented before implementation.
2. Changes should preserve the existing monorepo workspace structure unless there is a concrete need to change it.
3. Public deployments should remain compatible with static frontend hosting and a separately hosted backend.
